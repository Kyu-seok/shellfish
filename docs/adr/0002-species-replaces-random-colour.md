# Species replaces the Fish's random colour

A Fish used to be born with a random pastel Colour. It now has a Species (clownfish, goldfish, …), picked by the user when they name it, which fixes its shape and colours for life. Each Species has its own colours, such as a clownfish's orange and white bands, which no one tint can give. A Fish saved before Species existed asks for one the next time it is opened, and its old Colour is then dropped from the save. Species changes only how the Fish looks and its size; it never changes how it swims, eats or gets hungry.
